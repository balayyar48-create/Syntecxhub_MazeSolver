# Maze Solver using A* Search

This project implements an A* search algorithm to find the shortest path in a maze represented as a 2D grid.

## 🚀 Features

- Grid-based maze modeling  
- A* search algorithm  
- Manhattan distance heuristic  
- Path reconstruction  
- Unreachable case handling  
- Path visualization using matplotlib  

## 🧠 Algorithm (A*)

A* selects nodes using:

f(n) = g(n) + h(n)

Where:

- **g(n)**: cost from start  
- **h(n)**: heuristic to goal  

Heuristic used: Manhattan distance
